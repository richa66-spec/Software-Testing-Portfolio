# Software Testing Project

## Overview
QA project demonstrating manual testing of web and mobile applications and API test case documentation.

## Testing Techniques
- Equivalence Partitioning
- Boundary Value Analysis
- Functional Testing
- Cross-Browser Testing
- Defect Reporting

## Tools
Google Sheets, Excel, Jira, Postman

## Project Files
Excel workbook containing web, mobile, and API test cases, expected and actual results, and test execution status.
